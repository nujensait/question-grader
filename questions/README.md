# Тестовое задание: LLM-грейдер качества экзаменационных вопросов

## Контекст

В нашем продукте есть фича — **оценка качества экзаменационных вопросов с помощью LLM**.
Тебе дан статический файл [`questions.json`](./questions.json): **60 практических вопросов** с
вариантами ответов для сертификационного экзамена **SPHR (Senior Professional in Human
Resources)** — это профессиональный HR-экзамен. Вопросы на английском (как в реальном продукте).

Эти 60 вопросов — **разного качества**: от отличных (глубокие, хорошо сконструированные) до
посредственных (примитивные, со слабыми вариантами) и до вопросов с явными дефектами. Какие
именно — не сказано и специально не размечено. Твоя оценка 1–10 должна это качество отражать.

## Что нужно сделать

В своём локальном Laravel-приложении напиши artisan-команду:

```bash
php artisan grade:questions
```

которая:

1. читает `questions.json`;
2. для каждого вопроса оценивает его **качество с помощью LLM**;
3. выставляет каждому вопросу **оценку качества от 1 (плохой) до 10 (отличный)**;
4. сохраняет результат в файл `grades.json` строго в формате ниже.

> **Рубрику мы НЕ даём.** Ты сам решаешь, что делает экзаменационный вопрос хорошим или плохим, и
> сам проектируешь, как это оценивать. Подумай, чем хороший вопрос отличается от плохого, и заложи
> это в свою оценку.

## LLM

- Модель: **`gpt-5.5`** (OpenAI). API-ключ выдаётся отдельно.
- Если в твоём приложении уже есть сервис для вызова LLM — используй его.

## Формат входа (`questions.json`)

Массив объектов:

```json
{
  "id": "q_8f3a12",
  "question": "...",
  "answer": "...",
  "distractors": ["...", "...", "...", "..."],
  "explanation": "..."
}
```

## Формат вывода (`grades.json`) — соблюсти точно

```json
{
  "results": {
    "q_8f3a12": 7,
    "q_1c9244": 3
  }
}
```

- ключ — `id` вопроса из `questions.json`;
- значение — **целое** число 1..10.

Требования к выводу:

- в `results` должен присутствовать **каждый** `id` ровно один раз (все 60), все оценки в
  диапазоне 1..10 — **даже если LLM вернул кривой, неполный или невалидный ответ** (ретрай/добор —
  на твоей стороне);
- в `stdout` не должно быть мусора: JSON пишется **только в файл** `grades.json`.

## Что прислать

1. файл `grades.json`;
2. код команды (ссылкой на репозиторий или архивом).

## Ориентир по времени

~45–60 минут.
